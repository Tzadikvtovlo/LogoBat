# LogoBat

אוסף סקריפטי Batch ל-Windows המשתמשים ב-**FFmpeg** להמרה מהירה של כל תמונה לחבילת אייקונים מוכנה לתוספי כרום (בגדלים `16x16`, `48x48`, `64x64`, `128x128`, `256x256` בפורמט PNG עם שקיפות).

## סגנונות זמינים במאגר
- **`מעוגל-אנגלית.BAT`** — חיתוך ריבועי עם פינות מעוגלות (Rounded Corners).
- **`מרובע-אנגלית.BAT`** — אייקונים מרובעים בחדות גבוהה.
- **`עגול-אנגלית.BAT`** — אייקונים עגולים מלאים.
- **`משולב ישר.BAT`** — עיבוד מותאם בסגנון משולב.

## דרישות ואופן השימוש
1. ודאו שקובץ `ffmpeg.exe` נמצא בנתיב `C:\ffmpeg.exe`.
2. גררו קובץ תמונה על גבי סקריפט ה-`.BAT` הרצוי (או הפעילו והדביקו נתיב).
3. הזינו שם בסיס לקבצים — וייווצרו אוטומטית 5 קובצי PNG בגדלים התקניים לתוספי כרום.
